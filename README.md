### Featured Projects

**WorkPod — AI-Powered Workplace Simulation Platform**  
`MERN · Socket.io · Gemini API · Monaco · Jitsi · Excalidraw`  
Full-stack multiplayer platform where users practice real job scenarios with AI teammates. Features live human + AI room matching, synchronized whiteboard, embedded video meetings, code editor, and an automatic Gemini API key rotation system with strict JSON evaluation.

**BookMind AI — RAG Document Q&A System**  
`Python · LangChain · ChromaDB · HuggingFace · Streamlit`  
End-to-end Retrieval-Augmented Generation system that answers questions grounded in uploaded PDF documents. Uses recursive chunking, sentence-transformer embeddings, MMR retrieval, and context-only answering to reduce hallucinations.

**DPI Engine — Deep Packet Inspection System**  
`C++ · Multithreading · Networking`  
Packet inspection engine that parses PCAP captures across Ethernet/IP/TCP layers and extracts TLS SNI hostnames to classify HTTPS traffic. Multi-threaded pipeline with load-balancer, worker threads, and a CLI rule engine for blocking and live traffic reporting.

**Unity Games**  
`Unity · C#`  
- **Drone Race** — Custom drone flight physics with Tournament and Quick Race modes  
- **Pew Pew Heroes** — FPS with state-based enemy AI (patrol/chase) and gun mechanics
